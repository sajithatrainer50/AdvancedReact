# RTK extraReducers + React Router v7 + TypeScript

A beginner-friendly CRUD demo using:
- TypeScript only (`.ts` and `.tsx`)
- Redux Toolkit `createSlice`, `createAsyncThunk`, and `extraReducers`
- React Router v7 `createBrowserRouter` and `RouterProvider`
- JSONPlaceholder todos API

## Run
```bash
npm install
npm run dev
```

## Important note
JSONPlaceholder simulates POST/PATCH/DELETE but does not permanently store changes. Changes remain visible in Redux state until refresh.
