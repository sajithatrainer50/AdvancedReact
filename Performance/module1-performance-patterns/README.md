# NorthBridge — React Performance Patterns (Module 1)

Six standalone demos, one per concept, under `src/demos/`. Only one is active
in `src/App.tsx` at a time — the rest are commented out. To switch demos,
comment the current import/JSX line and uncomment the next one.

See the accompanying Run Guide for setup and DevTools instructions, and the
Study Guide for the concept notes and anticipated questions.

## Quick start

```
npm install
npm run dev
```

Runs on http://localhost:5101
